IMÁGENES DEL SITIO
==================

Carpeta preparada para las capturas reales del sistema (CRM, inventario,
paneles, flujos comerciales).

Todavía vacía: mientras no existan capturas reales, las páginas que las
necesitan (por ejemplo casos/la-ribera.html) muestran marcos placeholder
neutros, claramente identificados como "captura pendiente". No se generan
ni se inventan imágenes de producto.

Al agregar imágenes acá, reemplazar esos marcos por <img> con ancho y alto
declarados (para evitar saltos de layout) y texto alternativo descriptivo.
